### Fixed
- A DataGrid whose `height` is a grid-unit size token (for example `--plx-ref-size-100u`) now gets its maximum height again, so it virtualizes a long list instead of drawing every row; before, the holder had no height cap and 600 records drew 600 rows. Print and `afterprint` restore the virtual window as designed, and the virtual group header stays as the inert sticky copy (#1347, #1345, #1346).
