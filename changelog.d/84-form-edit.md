### Added

- DataGrid (ADR 0016, #84 F2): **Form Edit**. In a table whose editing mode is Form Edit (`editModes` offering both ways and `editMode="form"`, or the person's choice in the view menu), an edit asked for on an editable cell (Enter, F2, typing, a double click) opens the record in FormFlow's drawer titled "Edit {name}" (the key column's value) instead of the inline editor. One field per visible column, in order: an editable column is a Field (its title above its control, the column's editor at form size: input, number, text area, select, date, checkbox, combobox, tags, person or the application's own component); another column is its title over its value as plain text, an empty one a dash read as "No value". Save calls the new `onRecordEdit(record, changes)` with only the changed fields (without it, `onCellEdit` runs for each) and shows a Toast "Saved {name}"; a value a column's `validate` refuses shows under its field and stops the save; a rejected `onRecordEdit` keeps the form open with the values and shows the application's message. `formSurface="dialog"` uses the dialog. Loaded on first use. Dialog details, `openPanel`, `renderForm` and focus return follow (F3, F4).
