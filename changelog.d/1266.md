### Changed

- **Page templates:** each of the 15 page templates (`ListingPage`, `ContentManagementPage`, `LandingPage`, `HomePage`, `CreatePage`, `EditPage`, `MasterDetailPage`, `SplitWorkspace`, `SinglePaneWorkspace`, `FullScreenWorkspace`, `FullScreenExperience`, `DetailPage`, `SearchResultsPage`, `AuthenticationPage`, `ErrorPage`) is its own module, so an import of one page loads only its own code (for example `ErrorPage` adds 4.9 KB, not 24.5 KB, on top of the shared layers). The exports and props are unchanged (ADR 0052).
