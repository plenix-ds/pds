### Removed

- 311 utility classes nothing uses, deprecated since earlier releases and in 0.90.0 (#125, VERSIONING.md; ten others that the connected application CTM still uses are kept and stay listed as going away: `plx-u-absolute`, `-bg-transparent`, `-justify-center`, `-left-0`, `-right-0`, `-text-center`, `-top-0`, `-w-100px`, `-w-36px`, `-w-72px`): `plx-shadow-sm`, `-md`, `-lg`, `-raised`, `-menu`, `-modal`, `-ring`, `-ring-subtle`, `-underline-focus`; the `plx-span-*` classes that were not used (`plx-span-1`, `-4`, `-12` and `-16` stay); `plx-ratio-3-2`, `-3-4`, `-9-16`; `plx-control-toolbar`, `-standard`, `-dialog`; `plx-ai__mark`; and the `plx-u-*` utilities (the `fs`, `fw`, `leading` and `tracking` families, the one-off layout, background, padding, width and icon-box classes, and the rest of the list in `platform/standards/deprecated-classes.json` before this change). Each family's replacement is in the 0.90.0 *Deprecated* entry (a token on your own class, the Text component's variants, the layout parts). The going-away list holds only those ten. The system stylesheets are 20.4 KB smaller; every element's computed style on the application pages is identical before and after.

### Breaking

- 311 deprecated utility classes are removed (#125). A page written in HTML and CSS that still uses one loses that style. Use the replacement listed for its family in 0.90.0's *Deprecated* notes: `plx-shadow-*` becomes `box-shadow: var(--plx-sys-shadow-<name>)` on your own class; `plx-ratio-*` becomes `aspect-ratio: var(--plx-ref-ratio-<w>-<h>)`; `plx-control-*` becomes `min-block-size: var(--plx-sys-control-height-<role>)`; `plx-span-*` becomes the span classes that stay (`plx-span-1`, `-4`, `-12`, `-16`) or the part's own placement; `plx-u-fs-*`, `-fw-*`, `-leading-*` and `-tracking-*` become the Text component's variants (the text roles); the other `plx-u-*` classes become the matching layout part (Stack, Inline, Layout) or a token on your own class; `plx-ai__mark` has no replacement (nothing used it). React users of the components are not affected: no component produced them.
