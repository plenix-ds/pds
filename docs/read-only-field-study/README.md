# Read-only field study

The study behind the owner's read-only look (D-0106, #946), which #1043 registers as a named variation of PropertyGroup and PropertyList (D-0132).

- `index.html`: the interactive study. Open it in a browser. The **★ preset** is the owner's decision (CTM D-0050, PDS D-0106). The other options are the alternatives that were considered.
- Source: LighthouseCollection/CTM `docs/design/read-only-field-study.html`.
- All data in it is fictional. Three names in the CTM copy were replaced with invented ones for this public repository.

The decided look:

- porcelain tiles with a same-tint border, 2 per row, 16px gaps
- group heading 13px medium gold, 40px between groups
- label 11px regular navy, sentence case
- value 13px semibold; a status is a Badge with its icon
- inside a Panel, the card heading (14px bold uppercase) with the glow and an inset divider
