# Plenix Design System

- This site documents every public part of PDS in English and Arabic.
- Reference pages are generated from the TypeScript props, `tokens/*.json` and the OpenAPI spec. Fix the source, not the page.
- Every example here is built by `npm run build-storybook`, so an example that does not compile fails CI.
- The toolbar switches the writing direction between left to right and right to left.
