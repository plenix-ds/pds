# #781 wave 4: files that stay JavaScript (rulings)

Ruling format: what — why — cost if wrong. Written by PDS1-Component-Engineer-2.

| Files | Reader | Ruling |
|---|---|---|
| `platform/dev/*.js` (6 page scripts) | loaded by a plain `<script>` tag on pages, with no bundle | Stay JS. They run without the bundle; a build step would add a pipeline for 650 lines of dev tooling. Cost if wrong: no type checking on dev overlays. |
| `platform/providers/theme-boot.js` | copied verbatim to the CDN and the styles package (`build-packages.js`), run in `<head>` before React; `check-system.rules/size-scale.js` reads its `plx-size-steps` markers | Stays JS: it must run unbundled and a check reads its text. |
| `platform/loader/loader.js` | a `<script>` tag on every app page (`settings/index.html`) | Stays JS: it loads the bundle, so it cannot be inside it. |
| `platform/engines/plenix-engines.js` | copied verbatim to `dist/` and the CDN (`build-packages.js`) | Stays JS: published as is. |
| `platform/icons/layout.js`, `uses.js` | `require`d by Node build tools (`build-packages.js`, `build-icons.js`, `vite.platform.config.mjs`, `tools/icons/site-icons.js`) as CommonJS | Stay JS: those tools have no TypeScript loader. |
| `platform/icons/inventory/inventory.js` | generated by `tools/icons/build-inventory.js` | Stays JS: generated, do not edit. |
| `platform/i18n/en.js`, `ar.js` | read by path by 10+ checks and tests (`locale.mjs`, `built-in-words.js`, `strings-calls.js`, `w15c-packages`); `ar.js` is guarded by D-0012 | Stay JS: plain data catalogs; renaming touches every reader and the protected Arabic file. |

Converted in the i18n PR: `i18n/optional.ts`, `i18n/ar.optin.ts`, `i18n/ar.global.ts` (bundled by Vite; references updated in `vite.packages.config.mjs`, `knip.jsonc`, `tools/npm-esm/ar.js`, `platform/index.js`).
